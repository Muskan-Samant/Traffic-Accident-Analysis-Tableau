# Traffic Accident Analysis Dashboard

An interactive Tableau dashboard designed to analyze and visualize national traffic accident data, identifying high-risk zones, casualty trends, and distribution across different transport modes (Road, Railway, and Crossings).

## 🔗 Live Interactive Dashboard
👉 **[Click Here to View the Live Dashboard on Tableau Public]((https://public.tableau.com/app/profile/muskan.samant/viz/TrafficAccidentAnalysisDashboard_17809419573930/AccidentOverviewDashboard))**

## 🌟 Key Features & Insights
* **Executive Summary:** High-level KPIs showcasing Total Cases ($540,703$) and Fatalities ($212,027$).
* **Accident Distribution:** A sleek donut chart highlighting that **Road Accidents** contribute to the vast majority (~95%) of cases.
* **Top 10 High-Risk Zones:** Interactive bar chart sorting the most dangerous states/UTs (with Uttar Pradesh and Tamil Nadu leading).
* **Granular Sub-Category Analysis:** Detailed multi-axis charts comparing Road vs. Railway vs. Crossing cases per state.
* **Full Interactivity:** Implemented Action Filters allowing users to click any state to dynamically filter the entire dashboard.
